# Sistema de detección de somnolencia

Prototipo académico basado en landmarks faciales y redes convolucionales para la detección de eventos de somnolencia.

## Entorno
Python 3.11.9

## Modos
- O1: enfoque geométrico
- O2: enfoque combinado

## Modelos
- T1: clasificación del estado ocular
- T2: clasificación de bostezo

## Instalación
pip install -r requirements.txt

## Privacidad
Las grabaciones y fotogramas del conjunto G no se incluyen en este repositorio.
